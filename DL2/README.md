# CNN Hyperparameter Optimization

This project investigates how data augmentation and hyperparameter settings influence the performance of convolutional neural networks on the Oxford-IIIT Pet Dataset.

The dataset contains images of 37 cat and dog breeds.

## Project Structure

```text
src/
    data.py           # dataset loading, preprocessing, augmentation
    eda.py            # exploratory data analysis
    model.py          # CNN architecture (configurable layers/pooling)
    train.py          # training and evaluation loops
    seed.py           # reproducibility (random seed)
    experiments.py     # systematic hyperparameter search (Optuna)
    evaluate_final.py  # final training + evaluation of the best model
    main.py            # single baseline run (sanity check)

reports/
    results.md              # generated report
    eda_*.png                # generated by eda.py
    optuna_results.csv       # generated by experiments.py
    best_config.json         # generated by experiments.py
    confusion_matrix.png     # generated by evaluate_final.py
    misclassifications.csv   # generated by evaluate_final.py
    final_training_settings.json
    best_model.pt

requirements.txt
README.md
```

## venv launch
```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## running models

Run in this order:

```
python src/eda.py             # exploratory data analysis
python src/main.py            # baseline sanity-check run
python src/experiments.py     # systematic hyperparameter search (Optuna)
python src/evaluate_final.py  # trains the best config found above and evaluates it
```

`evaluate_final.py` automatically loads `reports/best_config.json` (produced
by `experiments.py`). If that file does not exist yet, it falls back to a
default configuration.

## notes
Image size used: 64 (base 128)
Random seed: 42 (fixed for random / numpy / torch, see `src/seed.py`)
Results and report: `reports/results.md` (auto-generated by `evaluate_final.py`,
some sections are marked `TODO` and need to be filled in manually)

## Model
Configurable via `PetCNN` (`src/model.py`):

```
[Conv2d -> ReLU -> Pooling] x N   (N and channel sizes configurable)
AdaptiveAvgPool2d
Flatten
Linear -> ReLU -> (optional Dropout) -> Linear
```

Pooling type (max/avg), number of conv blocks, channel sizes, dropout rate,
learning rate, batch size and augmentation are all tuned in `experiments.py`.
